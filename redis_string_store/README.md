# Redis String Store (C++)

This project demonstrates how to store and retrieve a string value from Redis using C++.

## Objective

Complete the missing TODO sections in the provided code to:

- Connect to Redis
- Store a string value
- Retrieve the stored value
- Print the retrieved value to the console

## Key Concepts

- Redis key-value storage
- Storing string data
- Retrieving values by key
- Basic database interaction
- Client-server communication

## How It Works

1. The program connects to a Redis server.
2. A string value is stored using a key.
3. The program retrieves the value using the same key.
4. The retrieved value is displayed in the console.

## Files

- `main.cpp`
  - Contains the Redis connection logic
  - Stores a string value
  - Retrieves and prints the stored value
